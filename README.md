# 🛒 E-Commerce Website (Django)

This is a basic E-Commerce web application built using **Django**.  
Users can browse products, view product details, and place orders.

---

## 🚀 Features

- User Authentication (Login / Register)
- Product Listing
- Product Detail Page
- Add to Cart
- Order Management
- Admin Panel for managing products
- Responsive UI

---

## 🛠️ Tech Stack

- **Backend:** Django, Python  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** SQLite (default Django DB)
